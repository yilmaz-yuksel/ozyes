# src_sayisal/: ÖSYM numerical summaries (not included)

This folder holds the five ÖSYM numerical summaries ("Yerleştirme Sonuçlarına İlişkin Sayısal Bilgiler"). They are used only in validation: their totals are transcribed in `dataset/osym_ozet.py` and compared with the dataset. They are not redistributed in this repository.

Run `python get_sources.py` from the repository root to download them here, under the names `2024_ilk.pdf`, `2024_ek.pdf`, `2025_ilk.pdf`, `2025_ek.pdf` and `2026_ilk.pdf`, with checksum verification.

---

**Türkçe:** Bu klasöre ÖSYM'nin sayısal bilgiler belgeleri gelir; yalnızca doğrulamada kullanılır. Depo kökünde `python get_sources.py` komutu onları buraya indirir.
