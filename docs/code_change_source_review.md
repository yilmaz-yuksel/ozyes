## Limits of interpretation

The combination of a source row showing the same university, a similar program, and a different unit name with an institutional announcement of the conversion supports the plausibility of the match. It does not, however, constitute evidence of equivalence regarding the program's curriculum, accreditation, entitlements, or statistical comparability. Historical scores should not be treated as being on an equivalent scale across years. The matching algorithm and the data were not modified.
